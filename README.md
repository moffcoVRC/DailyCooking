# まいにち、夕飯。

3人家族向け・スマホ優先の静的献立PWA。56種類の献立、買い物チェック、短い手順、家族のNG・苦手食材、食事記録、お気に入り、週間表示を実装。

## 起動

`npm start` で http://127.0.0.1:4173 を開きます（Pythonが必要）。HTMLの直接起動ではJSON読込・PWAは動作しません。テストは `npm test`（Node.js 18以上）。配信対象は `dist/` のみで、ビルド不要です。

## 週間献立（2026-09-15更新）

月曜〜日曜の7日分をまとめて選び、週内で同じ料理を重複させません。日付と候補から決まる固定の並びで、食事記録・評価・買い物チェック・閲覧順・冷蔵庫の在庫は選択に影響しません。NG設定の変更時も週全体で重複を防ぎます。候補が7種類未満の場合は不足日を空欄にします。

辛い物・ピーマン・レンコン・ししゃも・苦い物を共通NGとして候補から除外します。個別のNGは追加できます。苦手な食材欄はメモとして保存します。

パス・繰り越し機能は廃止しました。旧保存データは初回更新時にバックアップし、予定・買い物チェックを再構築します。家族設定と実際の食事履歴は保持し、過去の料理の記録を新しい予定に付け替えません。

## データ

`dist/data/menus.json` が献立の正本です。フルーツは別JSON。肉・魚はパック単位、基本3人前・30分以内。炊き込みご飯2種類は準備10分、浸水・炊飯を含む目安70分を別表示します。市販品の調理や水量は商品表示に従います。料理のタグは商品ごとの全原材料を保証するものではありません。

家族・評価・買い物・予定はブラウザのlocalStorage。端末間同期なし。NGは候補から除外し、既存予定の該当食材も警告。NG設定変更時は週全体を見直します。評価の最新記録が「また作りたい」の料理がお気に入りになります。

PWAは初回オンライン読込後に基本画面をオフライン利用できます。HTTPSまたはlocalhostが必要です。更新時はservice-worker.jsのCACHE名も更新してください。保存容量超過時は画面に通知します。

## GitHub Pages公開

保存先は https://github.com/moffcoVRC/DailyCooking です。公開する場合は、Settings → Pages → SourceをGitHub Actionsに設定し、Actions → Publish dinner app → Run workflowを実行してください。同梱ワークフローがテスト後にdistを公開します。サブディレクトリ公開にも対応する相対URLです。保存しただけではWebサイトは公開されません。非公開リポジトリでのPages利用可否はGitHubの契約と設定をご確認ください。

Safariの共有メニュー → ホーム画面に追加で利用できます。実機iPhoneの表示・ホーム画面追加は別途確認が必要です。
